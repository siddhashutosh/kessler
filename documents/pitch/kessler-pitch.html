T-01The problem

Orbit is filling up faster than the tools that keep it safe.

Mega-constellations have compressed collision-avoidance decisions from days to hours. Every operator now receives Conjunction Data Messages — but the tooling to read them is MATLAB-locked, commercial, or doesn't exist.

$1.7B

spent by the US DoD between 2000–2022 trying to replace its space-tracking software. It still shipped nothing.

2×

every conjunction arrives as duplicate, contradictory rows — one per object's perspective, plus a new row per screening update. Operators de-duplicate by hand.

0

lightweight open-source Python libraries for CDM parsing + collision-probability computation. NASA's reference tooling (CARA) is MATLAB-only.

T-02The system

Six agents. Raw surveillance data in, a decision out.

KESSLER is an autonomous pipeline: it pulls public orbital data, collapses the duplicates, computes collision probability two independent ways, and ranks every event by how urgently a human should care.

Agent 01
Catalog Sync
● CelesTrak GP
Agent 02
CDM Ingest
● Space-Track
Agent 03
Parser
● dedupe + validate
Agent 04
Pc Engine
● Foster × Chan
Agent 05
Risk Analyst
● triage + action
Agent 06
Publisher
● API + 3D UI
2

Independent Pc methods — Foster 2-D numerical integration, cross-checked against Chan's analytic series. Disagreement > 5% flags the event rather than hiding it.

3

Honesty levels for every number. Full-covariance computation, source-reported value, or a labelled conservative upper bound — the UI always says which one you're looking at.

<20

Requests per minute, enforced in code. A rate-limit governor keeps Space-Track happy and your account safe — cache-first by architecture, not by discipline.

T-04Why now

A wave of new CDM consumers is arriving. The shelf is empty.

2026
TraCSS goes operational. The US Office of Space Commerce is now distributing standardized CDMs to every satellite operator — thousands of teams that have never parsed one before.
Oct 2023
poliastro archived. The most popular open-source Python astrodynamics library went unmaintained; its successor fork has 42 GitHub stars. The ecosystem has a vacuum.
MATLAB
The reference implementation is inaccessible. NASA CARA's conjunction tools require a commercial license to run — a non-starter for smallsat teams and students.
253+
Indian NewSpace startups concentrate upstream (launch, hardware) while downstream tooling — 70% of global commercial space activity — stays underserved. KESSLER is built from India, on the infrastructure Indian operators already use.
